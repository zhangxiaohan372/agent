## 一、校区地图说明

太原理工大学现有四个主要校区，各校区均有流浪动物分布，管理策略略有不同。

### 1.1 明向校区（主校区）

- **位置**：山西省晋中市榆次区大学街316号
- **规模**：最大校区，面积约3000余亩，学生人数最多
- **校区特点**：绿化面积大，树木茂密，流浪猫较多；宿舍楼间隙、食堂后方是主要猫群聚集地
- **主要建筑参考**：
  - 图书馆附近：猫群密度中等，常有学生投喂
  - 一食堂、二食堂后方：流浪猫活动频繁，食物来源丰富
  - 东区宿舍楼群（1~6号楼）：固定猫群约5~8只
  - 西区宿舍楼群（7~12号楼）：有流浪狗出没，需重点关注
  - 中心草坪：动物密度低，偶有猫只路过
  - 工程训练中心附近：偶有受伤动物上报记录

### 1.2 迎西校区

- **位置**：山西省太原市迎泽西大街79号
- **规模**：中型校区，以研究生和部分本科专业为主
- **校区特点**：校区较老，建筑密集，角落多，流浪猫多栖息于楼道、储藏室附近
- **主要动物分布**：
  - 研究生宿舍楼附近：长期有固定猫群约3~5只
  - 教学楼地下层：冬季猫只常在此避寒
  - 校内小花园：夏季流浪猫聚集较多

### 1.3 虎峪校区

- **位置**：山西省太原市万柏林区虎峪南路
- **规模**：中型校区，以工科类专业为主
- **校区特点**：地形较复杂，有坡地，流浪动物较难管控；靠近校外，可能有校外流浪犬进入
- **主要动物分布**：
  - 实验楼群周边：固定投喂点2处
  - 宿舍区西侧绿化带：猫只常在此晒太阳
  - 运动场附近：偶有流浪狗出没

### 1.4 柏林校区

- **位置**：山西省太原市尖草坪区
- **规模**：较小校区，以部分专业低年级学生为主
- **校区特点**：校区偏小，动物数量相对较少
- **主要动物分布**：
  - 教学楼后侧绿化带：固定猫群约2~3只
  - 宿舍区楼道：冬季有猫只进入避寒

## 三、校园内动物投喂规定与禁区说明

### 3.1 投喂规定（应遵守）

1. **只在指定救助点投喂**：严禁在教室、图书馆、实验室等室内区域投喂
2. **定时定点**：遵循早晚两次固定时间，不要随意增加投喂频率
3. **投喂后清理**：投喂结束30分钟后将剩余食物和食盘带走或丢弃，不留垃圾
4. **不喂食人类熟食**：严禁将食堂剩余饭菜直接喂给动物，统一使用系统采购的猫粮/狗粮
5. **不私自添加新动物**：发现校外流浪动物不得直接投喂，需先上报管理员登记
6. **禁止在宿舍楼内私藏动物**：如发现动物受伤需临时救助，需联系管理员安排专用暂养区

### 3.2 禁止投喂区域

| 禁区类型 | 具体区域 | 原因 |
|---------|---------|------|
| 教学区 | 所有教学楼内及楼道 | 影响正常教学秩序，食物气味引发卫生问题 |
| 实验区 | 实验室及周边10米内 | 动物进入实验区存在安全隐患 |
| 食品加工区 | 食堂内部（仅限后门外） | 卫生法规要求，防止食品污染 |
| 医疗区 | 校医室及卫生间附近 | 免疫力低下学生聚集地 |
| 运动区 | 操场、球场内部 | 影响学生运动安全 |
| 行政楼 | 行政办公楼及访客区 | 影响校园对外形象 |

### 3.3 特殊情况处理

- **发现受伤动物在禁区内**：不要强行驱赶，立即联系社团管理员，等待专业处理
- **动物进入教室或宿舍**：通知辅导员或宿管，由志愿者协助引导出去，禁止打伤动物
- **动物与人发生冲突**：立即远离，上报管理员，禁止私自打伤或驱逐

## 四、校园动物救助点巡查说明

### 4.1 日常巡查要求

- 每位负责志愿者每周至少巡查所负责救助点2次
- 巡查内容：动物健康状态、食物是否充足、水碗是否清洁、保温设施是否完好
- 巡查结果需在系统中记录（更新动物健康状态字段）

### 4.2 巡查记录格式

每次巡查建议记录以下信息（可在系统备注或更新动物档案）：
- 巡查日期与时间
- 发现动物数量（比对档案）
- 健康状态评估（normal/attention/emergency）
- 异常情况描述（如新伤口、脱毛、行动异常）
- 食物/水消耗情况
- 是否发现未登记新动物
