# 喂养与救助知识库

> 分类标签：feeding / rescue / medical / sterilization / safety  
> 适用对象：校园志愿者、社团成员、普通同学  
> 来源：校园流浪动物管理系统内部知识库

---

## 一、日常喂养方法

### 1.1 喂猫基本原则

- 每天定时定点喂食，建议早7:00–8:00、晚17:00–18:00各喂一次，培养动物规律进食习惯。
- 每只成年猫每日干粮用量约为体重（kg）×30~40g，幼猫可适当增加。
- 喂食地点固定，避免随意更换，防止猫找不到食物来源。
- 喂食后30分钟内收走剩余食物，防止变质和招引害虫。
- 在寒冷天气中，可适量增加喂食量（约增加10%~20%）以补充热量消耗。
- 使用专用猫粮碗，不与其他动物混用，减少疾病交叉传染。

### 1.2 喂狗基本原则

- 成年中型犬每日饲喂1~2次，每次干粮约100~200g（依体型而定）。
- 大型犬一次喂食量可达300~500g，建议每天2次分食。
- 幼犬（3月龄以下）每天需喂食3~4次。
- 每次喂食后，确保有充足清洁饮水（不少于体重×50ml/日）。
- 户外喂养时，注意避开下雨、暴晒天气，选择有遮蔽的固定投喂点。

### 1.3 饮水注意事项

- 每天换一次清洁水，水碗每周清洗消毒一次。
- 夏季高温时，每天至少换水2次，防止水变热或滋生细菌。
- 冬季注意防止水碗结冰，必要时使用保温碗或频繁换水。

## 二、食物禁忌

### 2.1 猫的食物禁忌

| 禁止食物 | 危害说明 |
|---------|---------|
| 葱、大蒜、韭菜 | 含硫化物，破坏猫红细胞，导致溶血性贫血 |
| 葡萄、葡萄干 | 可能导致急性肾衰竭 |
| 巧克力、咖啡、茶 | 含可可碱/咖啡因，引发心律失常、抽搐 |
| 生鱼、生肉 | 可能含寄生虫（弓形虫、绦虫等），需煮熟 |
| 牛奶（大量） | 多数成年猫乳糖不耐受，导致腹泻 |
| 生鸡蛋蛋白 | 含抗生物素蛋白，影响维生素B吸收 |
| 骨头（细小尖锐） | 鱼骨、鸡骨易划伤消化道 |
| 洋葱 | 与葱类同样危险，即便少量也有毒 |
| 木糖醇（口香糖） | 对猫有强毒性，可致低血糖甚至死亡 |
| 酒精 | 极少量即可导致酒精中毒，严重可致死 |

### 2.2 狗的食物禁忌

| 禁止食物 | 危害说明 |
|---------|---------|
| 葡萄、葡萄干 | 引发急性肾衰竭 |
| 巧克力 | 含可可碱，引起呕吐、腹泻、心脏病发作 |
| 洋葱、大蒜 | 破坏红细胞，导致溶血性贫血 |
| 木糖醇 | 引发严重低血糖和肝衰竭 |
| 澳洲坚果 | 引起虚弱、高温、呕吐、颤抖 |
| 生面团（酵母） | 在胃中发酵膨胀，导致胃扭转 |
| 酒精 | 即便少量也会导致中毒 |
| 人类药物 | 止痛药（布洛芬、对乙酰氨基酚）对狗极毒 |
| 咸/重口味食物 | 导致盐中毒，出现多尿、脱水 |

## 三、常见疾病识别与初步处理

### 3.1 猫的常见疾病

#### 3.1.1 猫瘟（猫细小病毒）
- **症状**：精神萎靡、高烧（39.5°C以上）、呕吐、严重腹泻（带血）、食欲废绝
- **传播**：接触感染猫的排泄物、分泌物，粪口传播
- **初步处理**：立即隔离，不要给水（可能加重呕吐），用干净毛巾保暖，尽快联系兽医
- **注意**：病死率极高，不接种疫苗的幼猫死亡率可达80%以上，切勿拖延就医

#### 3.1.2 猫鼻支（猫疱疹病毒/杯状病毒）
- **症状**：打喷嚏、流鼻涕、流眼泪、眼睛有分泌物、食欲下降
- **初步处理**：用温湿棉布轻轻擦去眼鼻分泌物，保持温暖，补充水分，联系志愿者负责人登记
- **注意**：传染性强，应与健康猫隔离；天气变化时高发

#### 3.1.3 皮肤病（真菌、螨虫）
- **症状**：脱毛（圆形脱毛斑）、皮肤发红、痒、抓挠频繁
- **初步处理**：不要直接用手触摸脱毛区域，戴手套或用工具隔离接触，及时上报给管理员
- **注意**：真菌性皮肤病（猫癣）可传人，接触后立即洗手

#### 3.1.4 外伤
- **症状**：可见伤口、流血、跛行、异常姿势
- **初步处理**：不要强行移动动物，用干净布料轻压止血，立即联系社团负责人安排就医

### 3.2 狗的常见疾病

#### 3.2.1 犬瘟热
- **症状**：高烧、流鼻涕、眼睛有黄色分泌物、咳嗽、腹泻、神经症状（抽搐）
- **初步处理**：立即隔离，保持安静和温暖，避免刺激，立即就医

#### 3.2.2 细小病毒（犬细小）
- **症状**：剧烈呕吐、血便、精神极度萎靡、脱水
- **初步处理**：紧急情况，立即就医，不要自行喂水或喂食

#### 3.2.3 外伤/骨折
- **症状**：跛行、不愿移动肢体、肿胀变形
- **初步处理**：用木板或硬纸板临时固定，用布条轻轻包扎，不要强行扶正，尽快就医

## 四、绝育/医疗流程说明

### 4.1 为什么要推行校园动物绝育（TNR原则）

**TNR = Trap（诱捕）→ Neuter（绝育）→ Return（放归）**

- 控制校园流浪动物数量，避免无序繁殖
- 绝育后动物领地意识降低，减少攻击行为
- 减少发情期的嚎叫，降低对校园秩序的影响
- 绝育动物寿命更长，患肿瘤风险更低

### 4.2 绝育手术流程

1. **术前评估**：确认动物健康状况，体重需≥1.5kg（猫）/2kg（狗），无急性病
2. **联系机构**：联系合作兽医院或流浪动物救助基金会，预约手术时间
3. **术前禁食**：手术前8~12小时禁食，4小时禁水
4. **诱捕运输**：使用专用诱捕笼，避免强抓，动物入笼后用布覆盖笼体减少应激
5. **手术与恢复**：手术当天由社团成员陪同，术后在兽医院观察2~4小时
6. **术后护理**：
   - 保持伤口干燥，佩戴伊丽莎白圈（防舔）
   - 3天内减少剧烈运动
   - 7~10天后拆线（或使用可吸收线则不需拆线）
7. **耳标标记**：绝育后在动物左耳剪V形缺口作为标识（国际通用标准）
8. **放归记录**：在系统中更新动物档案，标注绝育状态、绝育日期

### 4.3 就医流程

1. 发现动物异常 → 拍照记录症状 → 在系统中上报健康状态变更
2. 联系社团管理员 → 确认就医必要性
3. 用诱捕工具或毛巾包裹将动物装入转运箱
4. 就医时携带动物档案信息（品种、年龄、过往病史）
5. 就医后更新系统中的健康状态和备注信息

## 五、捕捉受伤动物的安全注意事项

### 5.1 基本原则

- **不要徒手抓**：受伤动物处于应激状态，极易咬伤或抓伤人
- **不要追赶**：追赶会加重动物恐惧，可能导致动物逃跑到危险区域
- **保持冷静**：蹲下来，放低身体，避免俯视（俯视是攻击姿态）

### 5.2 安全诱捕步骤

1. **远距离观察**：先观察动物状态、伤情、所在位置，不要急于靠近
2. **用食物引导**：将猫粮/狗粮放在诱捕笼入口处，耐心等待动物自行进入
3. **使用诱捕笼**：社团备有专用诱捕笼，可联系管理员借用
4. **毛巾覆盖法**：对于无法诱捕的情况，可用大毛巾从上方快速覆盖动物，包裹后放入转运箱
5. **戴厚手套**：必要时使用皮质或加厚手套防止抓伤

### 5.3 被抓伤/咬伤处理

1. 立即用流动清水冲洗伤口15分钟以上
2. 用碘伏消毒
3. 立即前往医院或校医室，**24小时内注射狂犬病疫苗**（第一针必须在24小时内）
4. 按医嘱完成全程疫苗接种（通常5针，0/3/7/14/28天）
5. 在系统中记录咬伤事件

## 六、冬季/夏季特殊照护提示

### 6.1 冬季照护

- **保温**：在固定投喂点放置保温小屋（纸箱+泡沫+旧衣物），出入口朝向避风方向
- **防冻水**：增加换水频率，防止饮水结冰；可使用保温碗
- **增加食量**：冬季动物热量消耗增加，适当增加喂食量约10~15%
- **注意病情**：冬季是猫鼻支、犬瘟等呼吸道疾病高发期，发现打喷嚏、流鼻涕应及时上报
- **检查避风处**：关注动物常待区域是否有足够遮风避雨设施

### 6.2 夏季照护

- **防暑**：避免动物在烈日下长时间曝晒，关注宿舍楼阴凉处、树荫下的动物
- **供水**：夏季脱水风险高，每天至少换水2次，并增加水碗数量
- **食物防变质**：夏季食物30分钟内即可变质，喂食后尽快收走剩余食物
- **防蚊虫**：跳蚤、蜱虫、蚊虫在夏季活跃，注意动物是否有过度抓挠行为
- **预防中暑**：发现动物大量喘气、流涎、无力，立即移至阴凉通风处，用湿毛巾敷身体，立即就医
